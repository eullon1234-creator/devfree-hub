> O guia definitivo e catálogo interativo com as melhores ferramentas, bancos de dados, serviços de IA e APIs com **tiers gratuitos generosos** para desenvolvedores.

## 🚀 Funcionalidades

- 🔍 **Busca em Tempo Real**: Encontre APIs e ferramentas por nome, tecnologia, cotas ou tags.
- 💳 **Filtro "Sem Cartão de Crédito"**: Mostra apenas as ferramentas que não exigem dados bancários.
- ⚡ **Filtro "Possui API REST / SDK"**: Filtra por recursos com integração programática.
- 📋 **Ficha Técnica Detalhada**:
  - Limites e cotas exatas de uso gratuito (diário, mensal ou permanente).
  - Checklist do que está incluído no Free Tier e limitações conhecidas.
  - Links diretos para: **Site Oficial**, **Documentação da API** e **Página de Preços**.
  - **Snippets de Código Prontos** para copiar e usar com um clique.
  - **Dica de Desenvolvedor (Pro Tip)** para tirar o máximo proveito de cada cota.
- ⭐ **Sistema de Favoritos**: Salve suas ferramentas preferidas no navegador (`localStorage`).
- ➕ **Cadastro de Novas Ferramentas**: Formulário interativo para expandir o catálogo localmente.
- 🌓 **Tema Dark & Light**: Design moderno e responsivo com suporte a ambos os modos.

## 💻 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/eullon1234-creator/devfree-hub.git
   cd devfree-hub
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse no navegador: `http://localhost:5173`

4. **Gerar build de produção:**
   ```bash
   npm run build
   ```

5. **Deploy no GitHub Pages:**
   ```bash
   npm run deploy
   ```
